1. 我們評估了什麼

目標序列是全國每週新冠門急診就診人次（健保門診 + 急診），取自疾管署 NIDSS「傳染病統計資料查詢系統」的新冠病毒感染健保就診查詢；這是疾管署每週新聞稿與宣布流行期所用的指標。疾管署開放資料的健保檔只有門診與住院、RODS 檔沒有急診總人次，因此另以「開放資料門診 + RODS 急診」合成指標作對照（第 2 節），兩者都做回測。

模型是 Google TimesFM 3.0（330M 參數的時間序列基礎模型），零樣本、未經微調，逐層加入已知未來共變數（春節旗標、每週平日假日天數、季節相位）、過去共變數（RODS）與多變量聯合預測（門急診 + 門診 + RODS + 住院）。基準為 last-value naive、MA3、季節性 naive、AutoETS、Theta。評估指標：WIS、MAE、MAPE、MASE、80%/60% 涵蓋率、方向命中率、±10% 命中率；結果依年（2024、2025、2026）與全期報告。新冠與流感、腸病毒最大的不同是可用歷史只有 5 年、沒有固定季節週期、波峰逐年下降（2023 下半年起每年一波夏季流行加一波較小的冬春波，夏季波峰 19.6 萬 → 12.7 萬 → 7.5 萬 → 2.8 萬人次），因此回測窗不能沿用 2016–2025，起點只有 141 個，結論屬初步。

4. 怎麼解讀

  • 1–2 週最可靠。WIS 隨 horizon 上升（1,795 → 8,088）。新冠一波之內每週可變動 30–100%，4 週的預測只做規劃參考。
  • 看「續升機率」而非單點。每週頁以 9 個分位數推得「下週高於本週」與「高於暫行進入／脫離水準」的機率；在疾管署流行閾值確認前，不以單一數值判定流行期。
  • 變異株是模型看不到的。每一波由新變異株驅動，零樣本模型只從就診人次的形狀外推；波的起點通常慢 1–2 週才被模型捕捉，上升期的 1 週預測最有價值。
  • 2022 年在 context 內。單週 88 萬人次的 Omicron 大流行留在歷史裡；回測顯示含與不含（context 自 2023w12）結果相當，保留較長歷史。

5. 限制與注意事項

  • 回測只有 2024–2026 三個夏季波與兩個冬春波，141 個起點；每週預測存檔（forecast_log）累積的事前表現才是最終依據。
  • NIDSS 與開放資料為回補後數值，回測對「首報」情境偏樂觀；首報快照累積後可估回補係數。
  • 流行閾值數值尚未取得；暫行規則的參數（連續 3 週上升、低點 2 倍、峰值一半）為工作假設，確認後改依官方定義。
  • 重症序列自 2024w34 起（新病例定義），只做敘事；舊定義（2023/3/20–2024/8/31）未納入。
  • TimesFM 3.0 權重為非商業、非生產用途授權。
